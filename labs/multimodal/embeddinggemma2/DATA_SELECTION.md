# 파일럿 데이터 조사 기록

조사일: 2026-10-28. 실제 데이터는 아직 다운로드하지 않았습니다.

## 우선 검토: CHILDES-Aligned

공식 설명: https://talkbank.org/childes/access/Derived/CHILDES-Aligned.html

아동 음성 클립과 전사를 제공하는 파생 코퍼스입니다. 이미 분절된 오디오를 사용할 수 있어 첫 정렬 실험 후보로 선정했습니다. 원본 발화가 인접하면 합쳐질 수 있으므로 분석 단위는 반드시 단일 CHAT 발화와 같지는 않습니다.

파일럿은 ASR 정규화 전사 버전의 작은 표본으로 실행 호환성을 확인할 수 있습니다. 그러나 이 버전은 ASR 일치도에 따른 필터를 거쳤으므로 어려운 발음이나 발달 특성의 대표성을 보장하지 않습니다. Exp 4에는 이를 그대로 채택하지 않고 General 버전 및 원본 코퍼스와 비교해야 합니다.

다운로드 링크: https://media.talkbank.org/childes/0extra/CHILDES_Aligned.zip

이 링크는 공식 페이지에서 확인했지만 현재 응답의 파일 내용·크기·인증 요구는 검증하지 못했습니다. 문서에서 제시하는 메타데이터와 오디오 분할 아카이브 구성은 실제 내려받은 파일로 확인해야 합니다. 전체 오디오를 자동 다운로드하지 않습니다. 우선 메타데이터를 확인하고 작은 분할을 선택합니다.

## 대안: Gleason

공식 설명: https://talkbank.org/childes/access/Eng-NA/Gleason.html

여러 아동의 부모와의 상호작용 녹음이 있어 대안으로 검토했습니다. 공식 설명은 24명이며, 상위 색인 표의 N과 다르므로 코퍼스 원문 및 실제 참가자 ID를 기준으로 확인합니다. 실제 CHAT 파일에서 발화별 타임스탬프·화자·미디어 연결을 검증해야 합니다.

전사: https://talkbank.org/data/childes/Eng-NA/Gleason?f=zip

미디어: https://media.talkbank.org/childes/Eng-NA/Gleason

브라우저에서 미디어 경로를 열었을 때 “Login”만 표시되었습니다. 인증 후 실제 목록과 파일 가용성을 확인해야 합니다. 현재 로그인 정보나 세션은 확보하지 않았습니다.

## 데이터 확보 후 절차

1. 내려받은 메타데이터/설명 문서를 `data/raw/` 아래에 보관하고 출처·버전·라이선스·체크섬을 기록합니다.
2. 안정적인 아동 ID가 제공되는지 확인합니다. recording_id를 아동 ID로 대체하지 않습니다. 여러 세션의 동일 아동을 식별할 수 없으면 아동 단위 분석을 보류합니다.
3. 여러 아동에서 50~200개 클립을 고정 seed로 표집하되, 임베딩 유사도를 기준으로 표본을 고르지 않습니다. 선택·제외 기준과 전사 중복을 기록합니다.
4. 오디오 존재·길이·샘플레이트·정렬을 확인하고, 일부 표본을 청취합니다. 오디오와 메타데이터를 lab 기준 manifest로 변환합니다.
5. 2~5개로 실제 추론을 확인한 뒤 파일럿 전체를 실행합니다. 설치 및 실제 모델 호환성은 아직 검증하지 않았습니다.

진단 라벨은 원본 문서의 의미를 확인하기 전 이진 질환 라벨로 매핑하지 않습니다. 현재 코퍼스 선정은 잠정이며 다운로드한 파일의 구조·품질 확인 후 확정합니다.

## 접근 상태와 필요한 사용자 작업

TalkBank 공식 접근 안내는 전사·미디어 사용에 계정 등록 및 이메일 확인이 필요하다고 설명합니다: https://talkbank.org/childes/access.html

사용자가 TalkBank 로그인/등록을 완료하면 접근을 다시 확인합니다. 비밀번호를 채팅으로 공유할 필요는 없습니다. 다운로드를 직접 할 경우 파일은 이 lab의 `data/raw/`에 저장합니다. 외부 데스크톱이나 Downloads 폴더를 데이터 작업 위치로 사용하지 않습니다.
